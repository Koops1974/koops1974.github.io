1. Connect to your GitHub repository

This is remembered on this device only. You only have to do it once.

How do I get a token?
  1. Go to github.com/settings/personal-access-tokens/new (signed in as the repo owner).
  2. Token name: signage admin. Expiration: whatever you prefer (1 year is fine).
  3. Repository access: Only select repositories → pick your signage repository.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else as is.
  5. Generate token, copy it, paste it above. The token is stored only in this browser.
